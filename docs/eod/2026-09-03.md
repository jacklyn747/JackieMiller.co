## Locked decisions
- **Positioning:** *"Learning designed to be experienced, not endured; aesthetics are instruction."* Broad + legible + distinctive. The correctional/justice-involved work is the **flagship proof, not the label**. Hybrid **ID → LXD**.
- **Aesthetic:** flash-tattoo (Jackie's Procreate art) + Instrument Serif + Archivo + cream/ink/oxblood. Case studies stay **dark editorial** ("night mode"); homepage/work are cream. Cohesion via shared system + footer/next-project links.
- **Inverted pyramid governs ALL structure:** LEAD (payoff) → BODY (narrative) → TAIL (technical: frameworks, tech stack, rubric, docs). Recruiters scan → read → dig.
- **The Design-Decision Test** (every choice passes all 4): (1) solves a specific problem, (2) serves the learner + the approach, (3) is data-driven, (4) respects the learner's real-time perspective.
- **The shelf vs the gate:** reference library (Material, NN/g, Laws of UX, GOV.UK, WCAG, The Pudding, learning science…) is the source; the Test is the gate. Nothing pre-approved or banned.
- **Tech stack = portfolio common thread** (React, Next.js, AI-assisted build, a RAG tool) proving *"designs beyond drag-and-drop authoring tools."*
- **Copy rule:** the creative-writing credential is framed around **storytelling + the why** (humans are wired for story), never "my writing hits different." Every choice is data-driven.
- **No decorative 01/02/03 numbering** (AI tell).
